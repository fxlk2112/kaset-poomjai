LAN · ภายในฟาร์ม

เข้าเว็บฟาร์มได้
แม้อินเทอร์เน็ตขัดข้อง

เชื่อม Wi-Fi ภายในฟาร์ม แล้วใช้เว็บบน Pi 5 โดยตรง เราเตอร์และ Pi 5 ต้องยังมีไฟเลี้ยง

เตรียม iPhone / iPad ครั้งแรก

  1. ดาวน์โหลดใบรับรอง FARMULTIMATE LAN ผ่าน Safari
  2. เปิด การตั้งค่า → ทั่วไป → VPN และการจัดการอุปกรณ์ → FARMULTIMATE Farm LAN แล้วติดตั้งโปรไฟล์
  3. เปิด การตั้งค่า → ทั่วไป → เกี่ยวกับ → การตั้งค่าความเชื่อถือใบรับรอง แล้วเปิดความเชื่อถือสำหรับ FARMULTIMATE Farm LAN CA
  4. เชื่อม Wi-Fi ฟาร์ม เปิดลิงก์ด้านล่าง แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของเซ็นเซอร์เดิม
เปิดเว็บภายในฟาร์ม

บันทึกลิงก์นี้ไว้ก่อนเน็ตขัดข้อง ใบรับรองนี้จำกัดชื่อ farmultimate.local และไม่มีรหัสผ่านหรือข้อมูลบัญชี

สิ่งที่ใช้ได้ใน LAN

ผังฟาร์ม ระดับน้ำ สุขภาพระบบ หน้าพลังงาน และการทดสอบรีเลย์แบบไม่มีโหลด ข้อมูลพยากรณ์ใช้ชุดล่าสุดที่ Pi 5 เก็บไว้ พร้อมเวลาออกพยากรณ์

เมื่อเปิดเซสชันควบคุมใน LAN ระบบจะพักคำสั่งจาก Cloud จนออกจาก LAN หรือหมดเวลา ข้อมูลซื้อขายยังใช้งานผ่านเว็บออนไลน์เดิม

หากเพิ่งเปลี่ยนรหัสผ่าน Cloud ต้องปรับบัญชีสำรองบน Pi 5 ให้ตรงกันก่อน

อุปกรณ์อื่น: ดาวน์โหลดใบรับรองสาธารณะ

การติดตั้งใบรับรองเป็นขั้นตอนบนอุปกรณ์ของเจ้าของ คู่มือ Apple
